# Proyecto Integrador – Grupo 3 (UNIVALLE)
Solución de BI para evaluar la inversión en descuentos promocionales de un e-commerce (2016–2022).

Integrantes: Rocha Karin, Raña Sebastián, Lecoña Camila

## Contenido
- 02_Fase2_DataWarehouse: proyecto SSIS (Visual Studio) y respaldos .bak de MarketingOLTP y MarketingDW
- 03_Fase3: análisis estadístico y modelización (Rmd + html)
- 04_Informes: informe APA

## Cómo reproducir
1. Restaurar los .bak en SQL Server.
2. Abrir los .Rmd en RStudio, cambiar el nombre del servidor y hacer Knit.
